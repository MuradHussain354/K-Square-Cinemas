NIRAM — K Square Cinemas official website (static site)

HOW TO RUN
  Open index.html in a browser, or upload the whole folder to any web host
  (cPanel, Netlify, Vercel, GitHub Pages…). No build step needed.

WHAT TO EDIT
  js/config.js  -> email, phone, address, Instagram / YouTube / Facebook links, trailer link.
                   Empty values are hidden automatically.
  index.html    -> search for "TODO" to find where the director biography goes.

IMAGES (assets/images)
  niram-poster.jpg, still-1/2/3.jpg, director.jpg, logo.png, logo-mark.png, favicon.png, qr-trailer.png
  Replace a file with the same name to swap an image.
